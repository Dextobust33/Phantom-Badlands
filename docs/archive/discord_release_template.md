# Discord Release Post Template

Post in #announcements (converted to an Announcement channel). Ping `@Announcements` at the end.

```
# 🎮 v0.9.XXX — [Short Theme]

**[One-line hook about the biggest change.]**

## ✨ New
- Feature 1 — short description
- Feature 2 — short description

## ⚖️ Balance
- Change 1
- Change 2

## 🐛 Fixes
- Bug 1
- Bug 2

## 📥 How to Update
Just run the launcher — it auto-updates. If you use the standalone client, grab the new ZIP from the download page.

🌐 https://phantombadlands.com/download.html
📜 Full changelog: https://github.com/Dextobust33/Phantom-Badlands/releases/tag/v0.9.XXX

<@&ANNOUNCEMENTS_ROLE_ID>
```

## Tips

- Keep it scannable — bullets, not paragraphs
- Lead with the single most exciting change
- Max 3-5 items per section; link to full changelog for the rest
- The `<@&ROLE_ID>` pings @Announcements. Get the ID by typing `\@Announcements` in any channel (backslash escapes the mention and shows the raw ID), then copy the `<@&NUMBER>` form.
- In an Announcement channel, click "Publish" on the message so it crossposts to servers that follow yours
